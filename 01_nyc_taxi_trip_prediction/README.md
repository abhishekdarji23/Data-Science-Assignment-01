# 🚕 NYC Taxi Trip Duration Predictor

A small, real, end-to-end CRISP-DM data science project: predicts how long
a NYC taxi trip will take (and estimates a fare) from pickup point, dropoff
point, passenger count, and pickup time — served through a FastAPI backend
and a plain map-based web UI.

Reproduced (scoped down, "not fancy") from Project 01 of
[`dlmastery/data_science_examples`](https://github.com/dlmastery/data_science_examples).
See [`PROMPTS.md`](PROMPTS.md) for exactly what was asked and how this
build's scope differs from the original.

## Quickstart

```bash
python3 -m venv .venv && source .venv/bin/activate     # optional but recommended
pip install -r requirements.txt

# 1. Generate data (synthetic — see data/generate_data.py to swap in real Kaggle data)
python data/generate_data.py

# 2. Train the model
cd src && python train.py && cd ..

# 3. Run the app
uvicorn app:app --reload --port 8001
```

Open **http://127.0.0.1:8001** — click the map twice (pickup, then
dropoff), fill in passenger count & time, click **Estimate trip**.

Run the tests any time with:
```bash
python -m pytest tests/
```

## CRISP-DM summary

1. **Business understanding** — estimate trip duration & fare before a
   rider commits, from information available at request time.
2. **Data understanding** — `data/generate_data.py`; schema matches the
   real Kaggle NYC Taxi Trip Duration competition exactly.
3. **Data preparation** — `src/data_prep.py`; haversine/manhattan
   distance, bearing, time-of-day features.
4. **Modeling** — `src/train.py`; `GradientBoostingRegressor` on
   `log1p(trip_duration)`.
5. **Evaluation** — held-out, time-based 20% split. Current run:
   **MAE ≈ 81s, RMSE ≈ 122s, RMSLE ≈ 0.30, R² ≈ 0.89** (see
   `models/metrics.json` for the live numbers after you train).
6. **Deployment** — FastAPI (`app.py`) + a small web UI (`static/`).

## Honest limitations of this build

- **Data is synthetic**, generated by a physics-based simulator (distance
  ÷ speed, with rush-hour/weekend/noise terms) because this build
  environment has no internet access to Kaggle. Drop a real
  `data/nyc_taxi_train.csv` in and re-run `train.py` — no code changes
  needed. See `data/generate_data.py`'s docstring.
- **No video walkthrough is included.** Recording narration and uploading
  to YouTube isn't something this assistant can do. `WALKTHROUGH.md` is a
  written, code-ordered substitute, with a shot list at the bottom if you
  want to record one yourself in a few minutes.
- **This zip wasn't pushed to GitHub for you** — there's no GitHub write
  access available here. To publish it yourself:
  ```bash
  cd 01_nyc_taxi_trip_prediction
  git init && git add . && git commit -m "NYC taxi trip duration predictor"
  git branch -M main
  git remote add origin https://github.com/<you>/<repo>.git
  git push -u origin main
  ```
- Deliberately **not fancy**: no React build, no AutoML, no database — see
  `IMPLEMENTATION_PLANS.md` §9 for the full list of what was left out and why.
