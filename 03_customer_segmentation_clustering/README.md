# 🧩 Customer Segmentation Clustering

A small, real, end-to-end CRISP-DM data science project: segments
customers into behaviorally meaningful groups (KMeans clustering on Age,
Annual Income, and Spending Score) and serves it through a FastAPI backend
and a plain scatter-plot dashboard.

Reproduced (scoped down, "not fancy") from Project 03 of
[`dlmastery/data_science_examples`](https://github.com/dlmastery/data_science_examples).
See [`PROMPTS.md`](PROMPTS.md) for exactly what was asked and how this
build's scope differs from the original.

## Quickstart

```bash
python3 -m venv .venv && source .venv/bin/activate     # optional but recommended
pip install -r requirements.txt

# 1. Generate data (synthetic — see data/generate_data.py to swap in real Kaggle data)
python data/generate_data.py

# 2. Train the model (fits KMeans for k=2..8, picks the best by silhouette score)
cd src && python train.py && cd ..

# 3. Run the app
uvicorn app:app --reload --port 8003
```

Open **http://127.0.0.1:8003** — see the customer scatter plot colored by
segment, the segment profile table, and try "which segment is a new
customer in?" with your own age/income/spending values.

Run the tests any time with:
```bash
python -m pytest tests/
```

## CRISP-DM summary

1. **Business understanding** — group customers by behavior so marketing
   can target segments differently (e.g. converting "high income, low
   spend" customers vs. retaining existing VIPs).
2. **Data understanding** — `data/generate_data.py`; schema matches the
   real Kaggle "Mall Customer Segmentation" dataset exactly.
3. **Data preparation** — `src/data_prep.py`; selects Age/Income/Spending
   Score, deliberately excludes CustomerID and Gender.
4. **Modeling** — `src/train.py`; `StandardScaler` + `KMeans`, k chosen by
   silhouette score across k=2..8.
5. **Evaluation** — internal validity (silhouette + elbow), not held-out
   accuracy (clustering is unsupervised). Current run: **k=4,
   silhouette ≈ 0.40** (see `models/metrics.json` for the live numbers
   after you train).
6. **Deployment** — FastAPI (`app.py`) + a small scatter-plot dashboard
   (`static/`).

## Honest limitations of this build

- **Data is synthetic**, generated from 4 explicit latent customer
  archetypes (income/spending/age centers + noise) because this build
  environment has no internet access to Kaggle. Drop a real
  `data/Mall_Customers.csv` in and re-run `train.py` — no code changes
  needed. See `data/generate_data.py`'s docstring.
- **No video walkthrough is included.** Recording narration and uploading
  to YouTube isn't something this assistant can do. `WALKTHROUGH.md` is a
  written, code-ordered substitute, with a shot list at the bottom if you
  want to record one yourself in a few minutes.
- **This zip wasn't pushed to GitHub for you** — there's no GitHub write
  access available here. To publish it yourself:
  ```bash
  cd 03_customer_segmentation_clustering
  git init && git add . && git commit -m "Customer segmentation clustering"
  git branch -M main
  git remote add origin https://github.com/<you>/<repo>.git
  git push -u origin main
  ```
- Deliberately **not fancy**: no React build, no AutoML/hierarchical-vs-DBSCAN
  comparison, no database — see `IMPLEMENTATION_PLANS.md` §9 for the full
  list of what was left out and why.
