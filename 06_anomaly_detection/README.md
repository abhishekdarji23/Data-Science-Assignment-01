# 🚨 Anomaly Detection — Transaction Risk Scoring

A small, real, end-to-end CRISP-DM data science project: compares 3
standard unsupervised anomaly detection methods (Isolation Forest, Local
Outlier Factor, and a z-score statistical baseline) on transaction data,
and serves live risk scoring for new transactions through a FastAPI
backend and a plain dashboard.

Reproduced (scoped down, "not fancy," simple frontend + backend) from
Project 06 of
[`dlmastery/data_science_examples`](https://github.com/dlmastery/data_science_examples).
See [`PROMPTS.md`](PROMPTS.md) for exactly what was asked and how this
build's scope differs from the original — including an honest, surprising
result (see below) that was investigated rather than hidden.

## Quickstart

```bash
python3 -m venv .venv && source .venv/bin/activate     # optional but recommended
pip install -r requirements.txt

# 1. Generate data (synthetic — see data/generate_data.py to swap in real transaction data)
python data/generate_data.py

# 2. Train & compare all 3 methods
cd src && python train.py && cd ..

# 3. Run the app
uvicorn app:app --reload --port 8006
```

Open **http://127.0.0.1:8006** — see the method comparison table, score
a new transaction yourself, and browse the review queue of flagged
transactions.

Run the tests any time with:
```bash
python -m pytest tests/
```

## CRISP-DM summary

1. **Business understanding** — flag anomalous transactions for review,
   without a large set of confirmed-fraud labels to train on (hence:
   unsupervised methods).
2. **Data understanding** — `data/generate_data.py`; interpretable
   transaction features with a genuinely separable anomaly pattern baked
   in (higher amount, odd hours, high velocity, far from home, new accounts).
3. **Data preparation** — `src/data_prep.py`; feature selection, label
   excluded from model inputs.
4. **Modeling** — `src/train.py`; Isolation Forest, Local Outlier Factor,
   and a z-score baseline, all fit unsupervised.
5. **Evaluation** — PR-AUC as the headline metric (appropriate for a 3%
   positive class). Current run: **Isolation Forest ≈0.99 PR-AUC,
   z-score baseline ≈0.95, LOF ≈0.10** (see `models/metrics.json` for
   the live numbers after you train, and `AUDIT_REPORT.md` §3 for why
   LOF underperforms here).
6. **Deployment** — FastAPI (`app.py`) + a small dashboard (`static/`).

## An honest result, not smoothed over

Local Outlier Factor performed badly on this dataset. That's a genuine
finding, not a bug — LOF assumes anomalies are scattered, isolated
points, but this dataset's anomalies form their own dense cluster (they
share one alternate feature distribution), which defeats LOF's local-
density assumption. Isolation Forest and z-score are both *global*
methods and aren't fooled by this. See `AUDIT_REPORT.md` §1-3 for the
full investigation, including sign-convention checks that rule out "the
score direction was backwards" as the explanation.

## Honest limitations of this build

- **Data is synthetic**, with interpretable features and a genuinely
  separable anomaly pattern, because this build environment has no
  internet access to Kaggle. Drop a real `data/transactions_real.csv` in
  (schema documented in `src/data_prep.py`) and re-run `train.py` — no
  code changes needed.
- **No video walkthrough is included.** Recording narration and uploading
  to YouTube isn't something this assistant can do. `WALKTHROUGH.md` is a
  written, code-ordered substitute, with a shot list at the bottom if you
  want to record one yourself in a few minutes.
- **This zip wasn't pushed to GitHub for you** — there's no GitHub write
  access available here. To publish it yourself:
  ```bash
  cd 06_anomaly_detection
  git init && git add . && git commit -m "Anomaly detection: transaction risk scoring"
  git branch -M main
  git remote add origin https://github.com/<you>/<repo>.git
  git push -u origin main
  ```
- Deliberately **simple**, per your instruction: no React build, no
  autoencoder or One-Class SVM, no database — see
  `IMPLEMENTATION_PLANS.md` §8 for the full list of what was left out and why.
